# 鱼的心情桌宠 v1.0.0 — 第一个公开版本

把 `dsh-feiyu-mood` 的鲸鱼娘从 DSH 页面里搬到了 Windows 桌面上：一个透明的、置顶的、能聊天的小挂件。

## 主要功能

- **桌面常驻**：透明、置顶、可拖动，拖到屏幕边缘 20px 内自动吸附；不吃任务栏。
- **心情可视化**：七种情绪 + 亲密度 / 精力，数据来自 DSH 那边的 `feiyu-mood` 状态。
- **桌面直聊**：输入一句话，桥插件在 DSH Host 里做一次性模型调用，逐字写回气泡；不占会话上下文。
- **情绪与记忆**：亲密度/信任/精力会随时间漂移；聊天有热层（最近 N 轮原话）+ 温层（每 M 轮压成几条要点）。
- **她的设置**：记忆开关、保留/压缩节奏、“知道我在忙什么”、开机自启、气泡秒数、刷新间隔、模型覆盖。
- **英文界面**：设置里勾选即可在中文 / English 之间切换（`lang` = auto / zh / en）。
- **全屏自动隐藏**、**透明区域点击穿透**、**托盘 + 守护**（挂件被结束后会自动拉起）。

## 安装

1. 装好 DSH，并已安装上游插件 `dsh-feiyu-mood`；
2. 把仓库放进一个目录，按 `README.md` 的 Quick start 安装 `bridge/` 插件；
3. 双击 `widget/launch.vbs` 启动挂件（或在设置里勾“开机时自动出现”）。

## 已知限制

- 只支持 Windows（WPF）。
- 眨眼功能暂时关闭：上游只给了五张表情立绘，没有与睁眼帧同构图的闭眼帧。
- 界面字体按中文排版调过，英文下个别地方略紧。
